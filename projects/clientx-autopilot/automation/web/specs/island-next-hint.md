# 玩家始终知道下一件该做什么

## Given
- 玩家已开始新游戏并读完开场白

## When
- 玩家看左上角的提示
- 玩家摸摸 Bingo 并读完对话

## Then
- 摸之前提示写着「摸摸身边的 Bingo」
- 摸之后提示换成另一件心愿，并带着距离「米」
- 右下角不再出现「摸摸 Bingo」按钮
- 金色光柱立在下一件心愿的位置，Bingo 开始带路
- 右上角有小地图，点一下放大，上面标着池塘、茶屋和五只萤灵的位置
