# 拍货架后推荐的商品排在最前并显示单价

## Given
- 用户已登录，停在扫一扫页

## When
- 用户选择「超市货架」，写下需求「不辣的拌饭酱」并拍一张照片

## Then
- 识别请求带着登录凭证、场景、需求和压缩后的照片
- 结果里推荐的「酱油拌饭酱」排在第一个并带「推荐」标记和推荐理由
- 每个商品显示价格和按规格折算的单价
- 页面提示生词已存进生词本
