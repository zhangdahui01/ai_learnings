# 法式公寓软装优化方案：勃艮第与橄榄

状态：初稿（2026-11-23）。发布页以第二人称写给屋主本人（“您家”），本说明是仓库内的工作摘要。完整方案和 4 张搭配示意图发布在 [`docs/reports/french-soft-styling/`](../../docs/reports/french-soft-styling/index.html)。

依据是 9 张现场照片（客餐厅、壁炉墙、主卧）。出于隐私，原始照片不进这个公开仓库。

## 结论

- 硬装（石膏线灯槽、胡桃木柜体、洞石、紫脉大理石壁炉、玉石餐桌）是优点，不动。
- “土”感来自软装：全屋奶白没有深色、5 套花色同时出现、卡通抱枕和玩偶、功能椅盖毯、没有低位灯光、层架零散、餐边柜台面被电器占用、没有茶几。
- 方向：保留奶油底色，按 60-30-10 加入从硬装里取的两种点缀色，勃艮第酒红（壁炉大理石紫脉）和橄榄绿（餐椅、玉石桌面）。
- 分期：第 0 步零成本整理；第一期约 1–2 万元（抱枕、灯、茶几、灯罩、书和陶器）；第二期约 3–6 万元（地毯、外帘、艺术品、床品）。金额为粗估。
