# 法式公寓软装优化方案：勃艮第与橄榄

状态：初稿（2026-11-23）。发布页以第二人称写给屋主本人（“您家”），本说明是仓库内的工作摘要。完整方案、色彩板和 9 张原图标注发布在 [`docs/reports/french-soft-styling/`](../../docs/reports/french-soft-styling/index.html)。

依据是 9 张现场照片（客餐厅、壁炉墙、主卧）。按用户要求，发布页用了这 9 张的标注版。

## 结论

- 硬装（石膏线灯槽、胡桃木柜体、洞石、紫脉大理石壁炉、玉石餐桌）是优点，不动。
- “土”感来自软装：全屋奶白没有深色、5 套花色同时出现、卡通抱枕和玩偶、功能椅盖毯、没有低位灯光、层架零散、餐边柜台面被电器占用、没有茶几。
- 方向：保留奶油底色，按 60-30-10 加入从硬装里取的两种点缀色，勃艮第酒红（壁炉大理石紫脉）和橄榄绿（餐椅、玉石桌面）。
- 预算：全部小件，不换家具。第 0 步零成本整理；核心一套约 700 元（抱枕套、纯色盖毯、充电台灯、灯罩、托盘、蜡烛、花盆）；想更完整再加约 2,300 元，合计 3,000 元以内。金额为估算。
